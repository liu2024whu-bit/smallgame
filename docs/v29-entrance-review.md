# V2.9 · P2入口、设置、导航与指针

2026-10-25。保留门口环境、标题与献词，改进邀请的连续动作、设置的可发现性和导航的状态对应；没有为换风格而重画全部场景。P3起的逐关审查仍未完成。

## 实际迭代

旧邀请替换整段内容、重复三枚图标。第一轮新绘四件纸张部件，在同一个信封内展开，但闭合时纸角从底下露出，最后一步也缺少有意义的动作。第二轮缩正纸张尺寸，增加可点纸面翻到背面，保持同一DOM；刚性纸张用连续插值，不以不一致的整幅帧交替。纸的两面按真实朝向显示、读取，去掉最初不合适的opacity切换，避免翻转中途消失。

设置原来长滚动把存档藏在底部，现分声音／画面／进度；左右、Home、End可切页，切换后保留焦点，所有控件仍走同一偏好和存档逻辑。新卡通光标是小尺寸原生SVG，不新增跟随鼠标的DOM/动画；默认、点击、查看、抓取、握住和可使用各有形态，可关闭。触屏、高对比和不支持的浏览器保留原生回退；精确的输入与方向调整仍使用对应原生形态。

导航第一轮采用场景缩略图，第二轮发现背景图不包含解开的物件。选定方案抽出renderScenePicture，共用真实局部状态，再按整个源空间缩小；日历字和平台不会以原字号盖住缩略画。尚未打开的场景不展示生日内容，不伪造真实校园/小屋路线。

## 验证边界

同一信封在展开、翻面过程中保留；键盘和触屏可完成前置剧情，也可直接进屋、返回、继续。系统减少动态在动作中生效后没有残留运行过渡。设置页的后台位置编号随实际切页更新，邀请三步同样同步。光标关闭后刷新保留，新旧存档偏好按布尔值校验。

原生文件下载、新上下文读取、半途试印进度、坏文件保留与取消保存通过；设置改版没有换掉保存服务。布局、文字全量导出和线上结果见本批verification记录，未宣称真实iOS/Safari或无提示玩家测试。
