# 晚邮 · V2.9.7

基线是已发布的V2.9.6。本轮完成P6独立改造及新物件对库存、书架准入和旧档的必要影响。P7—P33仍按[总清单](v29-plan.md)继续，不把全程可达当作其他关卡的审美或玩法验收。[可视对照与操作录像](../review/postal/index.html)保留旧版、试作和当前画面；[结构化检查](v29-postal-checks.json)记录验证范围。

旧版手机四轮间距小于手指命中区；按钮与画中的窗槽比例不合。镜子只切换反字，邮匣开锁后仍是一张闭门图；借阅签只有叙述，没有可以拿起的物件。

本轮保留四枚邮戳→分拣格→匣上顺序→生日数字的推理，答案不依赖知道真实生日。先分开匣体、门板、锁扣与纸张；从整体靠近字轮，再回到真正打开的匣子。纸片翻面与镜读共享印刷内容，小镜中只有实际取到的视野，不把整页反字直接变正。观察姿态不作为隐藏通关条件。

借阅签从匣内实际拿起，才进入唯一collected库存并用于后续书架。旧合法进度保留通行，不让更新后已走过书架的存档失去工具。锁本身沿用已验证的纯数字规则，不另加答案或重复开锁状态。

先用可拆分素材做第一轮完整操作，再实际比较手机取景、轮距、镜中字号、门铰链与取物位置。材料、坐标、渲染、输入、动效分责；替换确认后删除旧邮匣单图、雨廊完成遮罩、旧邮片布局、假镜读和失效拨轮样式。运行只留当前版本，未增加运行依赖，也没有为了效果引入整套动画库。

## 推理与操作

两张邮片的四枚邮戳给出行列坐标，分拣格把坐标换成数字，匣上的桥／树／雨／窗确定顺序。南京那张的邮戳反印，小圆镜在有限视野里读出两枚记号。数字落在1029，但解题不依赖玩家先知道生日，也不以“看过哪一页”作为隐藏门槛。

整体、邮片工作台与字轮特写是同一处物件的不同观察距离。轻点邮片可以翻面，旁边一张可以交换；分拣格可以再拿近，回来仍保留卡片、正背和镜子方向。圆镜能从手边拖到镜托，也有直接放置；左右拖柄或使用键盘改变观察位置，不是一键切正整张纸。

四只字轮连续跟手，释放时落档；轻点、数字键与方向键调用同一规则。一次拖动只记一步，取消不提交。正确数字不会自己开门，锁扣需要轻点或向旁边拉动；错误尝试短促弹回，正确时门沿左铰链打开。借阅签仍夹在匣里，实际拿起才进入唯一collected库存，原处随后只留下小钉。

## 材料、空间与连续性

匣体、门前后、锁扣、纸座、镜托、印章与柜顶绿植使用自然栅格绘画；文字和数字按实际位置排印。镜框沿用P5的花叶纹黄铜柄，保持430/580比例。邮片上的校园画采用原图集完整分栏，不挤压或裁掉建筑。借阅签在匣内、物品栏和查看时共用同图同字。

邮片工作台的镜中画来自同一印刷层的负X映射与有限圆形视口，是平面镜读呈现，不宣称模拟完整三维光学。转镜、翻纸只属于临时观察，不另保存谜底状态。纸张、拨轮和拉扣有对应的原创材料声，音量与减少动态效果沿用全局设置。

雨廊远景与特写共用匣体、门板、数字和取签状态；完成后不是另盖一张“开门图”。柜顶绿植有落脚处，两张邮片铺在桌上。卡片/镜子的比例、镜中可读范围、门打开后的安全边界、柜内小钉和纸的接触位置都经过实际截图复核。

武汉画上的日字斋名实由[武汉大学新闻网资料](https://news.whu.edu.cn/info/1003/46681.htm)核对；南京那张的北大楼明确标为鼓楼，参照[南京大学官方页面](https://www.nju.edu.cn/info/4041/422051.htm)。这些是本作既有校园绘画的使用，不把它们冒称官方照片，也不虚构同行、课程或路线。
