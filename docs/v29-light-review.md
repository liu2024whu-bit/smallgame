# P5 借点光 · V2.9.4

原版是三组数字和一幅静止灯台，接近答案就减少模糊；尺、镜子、罩并不参与实际成像。本轮保留试印与云景汇合的位置，替换为可安装、滑动、升降、翻片和转镜的光影机关。

## 比较与取舍

1. 旧版：画外数字、直接给出2/1/3的刻度，删除旧lightbench和专属数字盘/伪模糊。
2. 第一版：分层器件和真实光路，桌面过小、上方留白太多，手机缩成一条。
3. 第二版：桌面取景收紧，发现手机控制拥挤；改为同一物理模型的独立竖屏相机和环境。
4. 当前版：补齐物件前后身份；圆镜统一花纹黄铜柄，透片材料/四角/雨窗在所有直接呈现中共用，支架与工具分开。去掉描不到的隐藏线，固定镜柄脚下、图集边界与遮挡。

[多版画面与实际录像](../review/light/index.html)。当前部分共新绘六份运行图片，刚性部件用连续位姿，不把随机重画当作动画帧。角色形变帧仍按P31继续。

## 玩法与证据

三工具顺序自由，灯也可以先开。透片滑动改变投影尺寸，木书签升降改变窗台上缘，镜子转动改变落点，翻片改变小伞的弯钩方向。纸上淡线只给轮廓，不给刻度答案；三层提醒主动展开。

128种配置联合唯一为[2,1,3]加透片翻面，最近错误与目标仍相差20个以上世界单位。合拢并不会自动完成；桌上铅笔可点按或拖到纸上，把可见的线描下。之后关灯、释放三处工具，纸稿独立留下。不是假设纸面有光电锁。

镜口有限，木片是有厚度的实体，长端点用展开镜面求阴影；不丢弃照不到镜子的单个端点。判断仅取镜口中看得到的雨窗锚点与木片远侧上缘，近侧下缘在光外，不成为隐藏条件。纸稿也使用当时的镜口与遮挡，不能补画被挡住的线。

## 实际验证

- 183项自动测试；反射律与独立展开投影、实体遮挡、全配置唯一解、任意装入顺序、真正描下、物件回收、端点/无效动作、旧档和依赖重建。
- 鼠标实际拖动三种器件、物品栏投到物理夹位、铅笔拖到纸上；连续预览不提前保存，一次松手对应一次历史。Esc、失焦、取消、撤销和重来可恢复。
- Chromium原生触摸拖动与取消、点按、快速交替开关、翻片、横竖屏切换；键盘全流程及减少动态。快速操作抓住当前位姿，单一动画驱动同时更新物件和投影。
- 发现并修复共享轻点去重：补发后原按钮被重建，迟来的原生click不能再认成第二次。曾尝试延后补发，但回归发现拖动后的快速三连点会漏一次，已删去延迟，保留零延迟并按物理按下位置去重。P4触摸回归通过。
- 实际下载半途与完成存档，分别在全新正式游戏上下文读取；当前值、安装/灯/翻面、独立纸稿、归还工具和下游场景一致。测试存档已删除。
- 完整26机关原生控件路线至生日结尾通过；这是可达性验证，不当作玩家盲测或与绣湖难度等同的证明。
- 241种实际状态、320/390/1440清晰字体、全部91个图片引用和83个不同资源解码；后台PIN、搜索、跳转、文字下载及正式/备份存档隔离。每次最新图片/共享呈现变更后重新核对。
- 演示使用真实控件操作，另配项目原创《窗边》，不是浏览器实时混音；实际游戏仍使用灯钮、夹具和纸张声音。

## 结构与保存

data/light.js管世界坐标、相机、图形与图集配准；light-geometry和calibration分别管几何与纯规则。light-drawing和light负责同源画面，interactions/light负责手势，motion/light仅拥有临时连续位姿与有限RAF，不保存另一份进度。帧间更新属性，不重建整幅SVG。

revision9只迁移真实的旧校准完成为已描纸稿，旧部分三档保留，工具从未安装状态继续。新档的缺字段/缺工具不能借旧字段跳关。纸稿有可验证配置，已完成时必须关灯且释放工具；图稿与当前空架参数独立。

书桌原灯/杯/花局部清去，新装置不压住试印盒；近景、远景、导航共用同一状态。删除旧校准转盘、光斑数字样式、旧独立图及原型单应变换代码，无新增运行依赖。
