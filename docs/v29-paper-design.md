# P3 试印：审查与制作决定（进行中）

基线：cf9fb9a。当前规则只有三项顺序的六种排列，画面直接写出操作名称并实时算出结果。问题不是能不能拖，而是它像一张关系题，没有拿取、放置、试印、比对与物件变化的完整过程。

## 保留与取舍

保留五枚图案、三种非交换变换和唯一顺序，避免破坏云景、留白、透片和夹层的图案身份。用新绘单色印痕替换本关的彩色贴花，不随便改掉跨关证据。首关靠无文字试纸认识工序、实际压印验证；后面的分支与汇合承接更深的组合，不靠增设无证据旋钮凑难度。

试算过可选进纸格数：24种配置没有唯一输出，并出现多组等价排列。它没有新的独立证据，暂不加入，避免外形复杂了却让推理更含混。

新外观采用本作虚构的手作试印盒，不声称真实古董印刷机。它与远景同一只盒子：薄木书签挑开窄夹扣，滑盖退开；三块印版可以交换；压柄真的把这次结果留在纸上，正确花纹让夹层松开。书签不消耗，后来还能抵住花架。

## 观察—操作—验证

1. 盒盖的花纹是目标，三张边角试纸分别记录一种印版的输入/输出。版片和试纸用同一枚不具先后暗示的扣记对应；不直接写“翻面/位移/交换”。
2. 夹扣有与薄木片匹配的缝隙。木书签可从手边拖入，也有键盘等价操作；开盖前印版被实物盖住，不能隔空移动。
3. 三块版片保持抓取点，拖动有让位/落点预览，取消不提交；键盘移动调用同一规则。只排对不会自动结束。
4. 压柄可拉，也可点按。抬手才提交一次试印；错误纸条留下实际结果，可与盒盖花纹比对。没有实时答案替玩家计算。
5. 成功后夹层/纸条与远景均有真实变化，透片奖励仍由core唯一库存派生。关闭、失焦、取消、撤销与重来有明确回退。

## 素材与结构准备

先画同旧书桌一致的关键构图，确认机身、滑盖、三槽、压柄、抽屉和试纸的位置；再拆为透明部件并补实际运动需要的姿态，不把整张概念图直接当成操作底板。单色叶/月/星/玫瑰/云印痕同一组制作。文字、开孔、扣记与输出严格由数据决定，不画假的线索。

规则继续纯函数；新增实际试印状态、开盖状态及有界印次标记，修改配置不伪造已经印出的纸。历史V2合法完成必须显式迁移，不因为新增按柄步骤丢失透片；新存档不能凭旧字段跳过实际压印。所有旧主线/夹层见证走法、完整链、保存与后台夹具随规则一起核对。

试印盒的固定空间、近远景标定、临时手势、材料动作和音色分别负责。需要时抽出共享场景更新键与动作音色，删除原来的纸条按钮墙与重复处理。本项目完成以后，P12仍要单独复核逆推玩法，不能把共享材质更新算作P12完成。
