# 光遇纸人 · 造型回访

本轮重新查看了发型的正面、背面和侧面，以及面具实际佩戴后的模型。旧纸人和旧收藏分别存在蓬松尖发、方形帽扣、闭眼红额纹及发光黑脸的问题。菜单图标不能作为佩戴模型的替代证据。

- 正太使用[鸣谢收藏家实机五面图](https://wiki.biligame.com/sky/旅行先祖：鸣谢收藏家)：圆而贴头的短发、非中分斜向刘海、克制的两侧发尖和单翘发。高个黑脸与矮个面具共用这一发型的识别特征。
- 经典巫师帽参照[实机展示](https://www.9game.cn/skygy/4781959.html)：倾斜宽帽檐、弯尖、嵌套菱形装饰及自带白发。不能把新款长发帽、临时帽子魔法与本稿混为一套。旧方扣及误画的长袍已替换。
- 矮人面具参照[佩戴模型](https://sky-children-of-the-light.fandom.com/wiki/Hide%27n%27Seek_Pioneer)，使用浅色面型与圆形眼部光感；额纹可被刘海遮住，不再照菜单图标画成闭眼红纹。[黑脸佩戴模型](https://sky-children-of-the-light.fandom.com/wiki/Proud_Victor)仅保留很淡的眼睑阴影，不画两颗发光圆眼。
- 樱花使用[2021年花憩节的花织发型展示](https://wiki.biligame.com/sky/2021年花憩节)：低双尾、短刘海、贴面的长发束和侧面花结。不是高双马尾或长辫。
- 全套服装参考[火先知实机展示](https://wiki.biligame.com/sky/旅行先祖：火先知)：短交领上衣、宽腰带、灰蓝分腿宽裤、靴子；斗篷本轮保持黑外层与橙内衬的蝙蝠轮廓。[童真面具](https://wiki.biligame.com/sky/2026年儿童节)独立记录，不能将其睫毛造型混入矮人面具。

先纠正双人稿，再拆成单个人物修正刘海、面型、帽饰与裤装；未采用仍中分的第一稿。当前四个人物各自完整取框，帽尖、衣摆、尾发和靴尖留出余量。它们是参照实机的水彩纸人再创作，不是官方原图；身份细节仍接受后续目视反馈，不能靠标签或尺寸检查宣称完全还原。
