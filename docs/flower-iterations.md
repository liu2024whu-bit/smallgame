# 花架：从一关开始做对照

本轮先完整打磨“挪挪花盆”，没有把其他机关都称作经过同等程度改版。旧版、第一轮和当前第二轮的实际页面保存在[三版对照](../review/flowers/index.html)，含可放大的初样／完成后与约18秒操作录像。

## 当前体验

同一摇柄带动标记的两盆。转到边界时，两盆一起停住；书签制动一盆后，另一盆仍可动。默认高度为0/1/2，胶片对应目标3/2/1。只有成对移动时到不了目标，书签仍是逻辑必需品，不只是装饰。

鼠标／触屏可直接抓住摇柄正反转，花盆连续跟手，抬手落入刻度；点按前进一格，方向键可以来回转。一次连续转动只提交一次历史。Esc、指针取消、失焦和关面板均不提交临时预览。

书签支持拖入、拖出，以及先拿起再点槽；拿在手里时扩大槽口区域，避免手机上的摇柄抢到点击。新绘侧面姿态跟着槽位运动，不再把正面图片转成截断的形状。取出后回到架边，工具仍可继续用。

远景底画移除固定花架，改用独立木架与同一组花盆、摇柄和书签部件。三个立柱等高，平台按真实进度停放；移到一半返回、解开后返回、快速换景，都保留一致状态。旧完成图中的花架遮罩已删除，避免两套画面叠在一起。

## 动作与声音

平台和摇柄共用有限过渡，按住时按四分之一圈连续预览，松手才落格。书签有入槽、退出和架边归位，碰边轻微回弹，完成窗光不遮挡控制。减少动态效果可随时终止装饰。

卡齿、转动、入槽、抽出、碰到头、松手和盖章使用不同短材料声；首次键盘操作也能听到，静音后不再触发。对照页单独提供音色小样，录像配游戏原创琴声，不将配乐冒充机关实录。

## 实际检查

- 真实鼠标拖动：一格联动、书签取消／放入、两格连续转动、碰顶停住、反转通关；按住期间保存的状态保持原值。
- 一条实际路径为：左柄正转一格 → 书签抵住中间 → 左柄正转两格 → 中柄反转一格。到3/2/1后自动释放书签，托板到手。
- 实际从通关花架返回书桌，打开纸盒夹层，确认后续主线仍可继续。
- 256种高度／制动组合均能走到目标；正反转仍不能免去书签；真实上下限拒绝越界；旧部分进度保留；多格转动只撤销一次。
- 手机实际拿起、放入、取出书签，翻近看胶片；减少动画后两帧检查，运行动画为0。单关实玩、远景往返和录像均无pageerror。
- 全局218种页面状态另做桌面／手机与清晰字体边界回归；这类自动检查不能代替审美判断或玩家盲测。

规则、坐标、手势与动作分开：`puzzles/flowers.js`、`data/garden.js`、`ui/puzzles/flowers.js`、`ui/interactions/garden.js`、`services/motion/garden.js`。旧书签处理器和旧花盆动画归属已删除，避免同时驱动同一物件。
