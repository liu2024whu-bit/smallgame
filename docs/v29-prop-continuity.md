# 物件连续性 · 2026-10-25

用户补充：同一物件的前后设计不能差得太多，也不能穿帮。这是全局要求，后续每关及P29—P33继续核对，不能因完成P5就宣称全部道具已查完。

验收顺序是来源、物品栏、放大查看、抓在手里、装入机关、近远景、取回、后续复用。物件的材质、轮廓、花纹、穗子、孔位和正反面保持一致；支架、光照与透视可以变化，不能凭空改掉物件身份。碰到不一致，先判断是改本体、改支架，还是替换呈现，不再为每个页面另造一张近似图。

| 物件 | 固定识别特征 | 本轮检查与后续边界 |
| --- | --- | --- |
| 木书签 | 浅木、棕穗、校园建筑刻纹和「武汉大学」 | P3/物品栏完整木牌；P5平放仍保留刻字和棕穗，取框移除相邻镜柄碎片。P11侧姿已存在，仍按P11/P29复核 |
| 棉线 | 白棉线、木线轴 | P4从同一库存牵线；展开成细线有实际动作。P9/P16继续检查线径、绕法与针路 |
| 小圆镜 | 黄铜圆框、花叶纹黄铜柄 | P4奖励/物品栏沿用原图；P5取消误画的木柄，按原镜重绘同款正视角。P6/P21后续使用仍检查相同身份与镜像关系 |
| 透片 | 薄方片、四角灰记号、淡雨窗 | 单一材料与LIGHT_INK共享图形；P3奖励、物品栏、手边、检查、拖影、P5和P17覆片同步。P5黄铜框为固定支架，取回透片后仍留在桌上。P7/P10/P13/P14完整玩法仍待各关审查 |
| 摇柄 | 黄铜折角、木手握、方轴 | P4/门口使用库存同图；P9/P11的传动/握柄继续审查 |

| 四张画页 | A玫瑰、B云、C雏菊、D星，纸角标记 | P15/P16继续核对纸页正背、排序后身份和装订后的图形 |

P5额外核对：镜面抬高后，黄铜柄停在桌面上；画纸挡住后面的支架，点击也不能穿过纸。镜口外或木片挡住的线不会被描出来；纸稿取自当时真实可见的投影，而非完成时另换完整图案。修改镜口后重新穷举128配置，唯一解与旧合法完成仍保留。
