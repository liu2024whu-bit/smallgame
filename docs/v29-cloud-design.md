# P4 · 两面的云：审查与选定方向

2026-10-25。上一轮为实际进展：9336387已发布V2.9.2，Game checks与Pages成功，并在线以触摸操作完成试印和播放演示。本轮从干净工作树继续P4；P12/P13、角色收藏及其他项目仍各自待审查。

## 旧版问题

- 画外三个数字盘在变，画里的云、牵引绳和纸景基本不变；换数字只是另一张图案。
- 背板三条横线不能解释规则(a+b, b+c, a+2c)，图和实际联动不相符。
- 两张前挂签和一张背签直接贴在图上，图案对号容易变成穷举数字。
- 翻面走核心move，计入撤销，完成后又被锁住；看另一面不该算一次解谜或在完成后消失。
- 近景矩形纸景与远景拱门物件不同。角色服装虽有研究记录，仍不能仅凭标签宣称准确。

## 玩法选择

保留64种四档输入及唯一联解[3,2,2]，保留线索/镜子/摇柄和后续关系；改变可见证据的表达。不是继续让数字决定一枚突然变化的图案。

两只前窗、一只背窗，各由两片可转纸环组成一枚分开的图形。两片到同一角度时，纸上的两半合成一只鳐、一只纸鸟或一颗星。位置无需朝上，合拢才是证据。每个线轴牵着两处纸环；一处合上，另一面可能又错开，需要前后核对。

共用规则的对应如下，图和判断取同一份定义：
- 前左：外片角度a，内片角度T0-b。
- 前右：外片角度b，内片角度T1-c。
- 背窗：外片角度a，内片角度T2-2c。
两半合拢当且仅当原来的三条关系成立。背面的大驱动轮与半径一半的小轮真实以两倍反向角度显示c的传动，不画无关的假绳。只看正面有4组可能；背面确定其中一组，难点来自两面的同一组部件。

棉线用于绕线轴：可从手边拖到某个轴，让它前进一档；也可直接牵转轴，点按/键盘有等价操作。线不消耗，随后继续穿线。没有线也能先观察，不能凭空获得工具或隔着盖子改变进度。

## 交互与状态

- 转动在实际线轴上发生，拖动实时预览所有受牵引的纸环；抬手只提交一次，Esc/失焦/关闭取消。四档有刻痕和吸附，数字不铺在画面上。
- 纸景沿实体支点翻面，两面对应同一物件。翻面是临时视角，独立于规则进度、历史和完成锁定；背面轴位按真实镜像排列，旋向也随视角对应。
- 完成后纸环保持，侧扇展开露出镜子与摇柄；回到窗边和导航仍能看到相同变化。奖励只由core库存派生。
- 已完成也可看正背两面，不能再次改动答案。减少动态随时收束，不等动画播完才能继续操作。
- 原有合法完成和半途四档值保留。移除cloud的旧back进度字段，不借兼容之名同时留两套视角所有者；P13和借光的旧规则暂留给各自项目处理。

## 素材先后

先定纸环/线轴/翻转的几何，画一张关键构图；再拆前壳、后壳、纸环、绕线轴和侧扇。环境与可动物体分开，功能图形用同源路径精确拼合。服装按公开参考另绘纸艺小人，不拿旧发型标签代替目视核对；不读私人照片/信件。

近景保留窗台的蓝天与光照，远景移除旧拱门占位后放同一只新纸景。不会用概念整图盖掉可操作部位。人物、木扇、圆窗和轴彼此留出边界；本体及动作不过框。

## 必须验证

全部64配置的图形/规则一致、所有状态可恢复、两面各联动及背面2倍关系；真实鼠标/触屏/键盘、连续转动与取消/撤销；翻面不写进度且完成后可看；工具拖放/复用、旧档、镜子/摇柄到借光/纸屏的下游、近远景和导航、大小屏、文字及边缘。保留旧版与至少两轮实际调整，清掉被替代的数字盘/叠图，更新后台和演示后发布。没有玩家盲测前不把开发者可解等同于已达到绣湖难度。
