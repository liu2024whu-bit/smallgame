# 素材和动作制作底稿

与[v29-plan.md](v29-plan.md)共用项目编号。这是制作准备，不是已完成素材清单。每个项目先确认玩法和关键姿态，再按需要补画；构图、锚点和可读性通过后才扩充同组帧。

| 项目 | 优先检查的图层/状态 | 连续方式与检查点 |
| --- | --- | --- |
| P2 邀请 | 已新绘背板、前袋、翻盖、信纸四部件；正反字由HTML排印 | 同一对象连续展开/抽出/翻面，刚性纸张插值；闭合不露纸，翻面不隐去，两面不重复读字 |
| P3/P12 试印/夹层 | 印床、纸张、工序件、试印与最终输出 | 纸的输入/输出身份、送料与压印接触关键帧；印记必须取自真实变换结果，回访使用同一台物件 |
| P4/P13 云景/留白 | 正反纸景、绳/滑轨、挂签、透片 | 背面与连线同源；固定轴/导槽；留白由几何决定，不另画一张近似答案 |
| P5 借光 | 尺、镜面、罩与投影 | 影子随真实参数变化；有遮挡、接触和正确端点，避免固定光晕冒充投射 |
| P6 晚邮 | 两张邮片、镜读、字轮与锁扣 | 纸边完整、四位数字不挤；镜像与拉扣同一空间 |
| P7 书架 | 五本不同书脊、借阅签和两枚角色书签 | 先检查画的身份/边界，再做抓取、抽出和插回；落位与书签不分离 |
| P8 纸屏 | 折页、正背画与接缝 | 沿折痕开合，正反线由数据控制；不用九张孤立人物卡 |
| P9/P10 放映 | 线轮、导槽、胶片、遮光片与花瓣 | 轴心稳定；连续穿线/放映与时间线一致；花瓣形变按关键姿态补帧 |
| P11 花架 | V2.8木架/摇柄/侧书签已有；待本轮复核 | 平台、花盆、制动和穗子接触，近远景同规则；补的是物理细节，不重复整景 |
| P14 字间 | 两条孔带、字表、键帽和搭扣 | 真实开孔/反印；按下/弹回和拉扣各有反馈，字符保持完整 |
| P15/P16 画页/装订 | 四张不同画面、页背、纸孔、针与线 | 保留每张纸的身份，穿线一笔跟手；收针后翻起装订完成的画册 |
| P17/P18 巧克力/可可 | 独立巧克力、透片、玻璃壶、液面/细流 | 取开留下真实空位；倾角、壶口、流向、容量和液面一致 |
| P19/P20/P21 准备台 | 五种糖、碟、纸带两面、卡片、镜子和匣盖 | 分糖、覆盖和解带来自真实规则；收走/打开后保持现场变化，匣内小兔时态正确 |
| P22/P23 日历/迷宫 | 夹页、字轮、圆环、固定星、小球 | 线索/刻度由代码排印；圆环连续转，小球沿真实可通行路径 |
| P24/P25 天平/抽屉 | 砝码、秤盘、支点、木销和抽屉侧面 | 接触、重心与受阻原因可见；运动后能够原路恢复 |
| P26/P27/P28 翻花/拼木/音乐盒 | 木片正背、图案完整接缝、六槽音钉/曲谱 | 同步联动/转向/落位；拼图抓取点和安全边缘；音高以图像证据可解，不强制听力 |
| P29/P30 收藏/校园/小记 | 官方造型参照、纸件、图章、不同收藏动作与彩蛋 | 先查事实与来源，再做风格适配；不贴生硬白底图、不盘点礼物、不重复同一种展览 |
| P31 猫狗/角色 | 待按实际动作检查猫狗睡/醒/转头/受摸，小黑抬爪/收手等 | 定脚下/头肩/视线锚点；先起势、接触、回落，再补中间帧；每组固定光线、比例和背景 |
| P32 生日/结尾 | 点烛、焰、愿望、礼袋开口与米色小兔 | 火焰可轻动；拆袋连贯，祝福留白；插曲结束返回原曲位置 |

人物需要补帧时参照已核对的官方造型及本作接受的画面；不把再创作称为官方原图。手绘帧只负责形变，平移、转动、柔光与遮挡尽量复用原有部件；帧数由动作需要决定。每组记录完整取框、透明边缘、脚下/支点、时间与减少动态静帧，不把批量随机生成当作动画。

预载只覆盖当前与紧邻的可达场景/动作；新组先检查最小关键帧，不提前生成大量尚未确定玩法的图。操作和结果不依赖等待装饰动画结束。测试同时看实际鼠标/触屏/键盘、声音、近远景、旧档与后台文案，不能只看漂亮的单张图。
