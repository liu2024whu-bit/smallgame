# 纸屏里的字 · P8制作与迭代

基线e563135（V2.9.8）。本轮集中改纸屏，其他关卡与角色仍按[持续清单](v29-plan.md)逐项推进。选择三位柱的纸上形象、水纹、风痕与白蛇形成画面，不把每个喜好、校园和回忆都塞进这一关；无需角色冷知识，也不要求记住私人日期。

原版九张卡片各配一段折线，小屏改成三行后破坏相邻关系。第一轮改成连续翻片、字轮和原处取物，但读到908就开锁，后半段发现太少。用户提出难度不足后停止发布这版，比较“再加一层换算”和“空处也是线索”，选后者做操作原型。它仍需实际玩家反馈，不能用操作数量或代码测试宣布达到绣湖的难度。

当前前层是九片双面纸，图案分在两面。合拢后的9、0、8围出四处镂空；后面另一张静态纸画已经画着墨迹，位置和转向不同，露出的部分也不同。玩家能通过空处直接挪动或转向后层，实心处仍操作前片；纸角提供另一种抓取和键盘入口。辨认后再拨字轮、拉锁扣，挡板升起后分别拿画页B与槽轮。908不再开锁，也没有“读过某页”“看过提示”的隐形门槛。

用户指出横穿图案的线像划痕。本轮已撤掉接线、两端、样式、坐标计算和旧端口表；前层判断只描述画面姿态及旧档兼容，不再以接线为新玩法依据。没有用降低透明度掩盖问题，也未补一组新辅助线。

三张全纸重绘没有投入当前运行：背景透明度、灰角和边框会破坏一致性。当前保留同批水彩墨画，加静态后层与栅格镂空。字轮纸带、纸画、画框、挡板、槽轮和画页按实测像素注册，物件落在实际匣底。远景复用同一纸屏，摆在原柜面；机关初样、开匣未取、部分领取与空匣保持同一库存。

结构分责：screen纯规则、位置/转向与验证；data/screen源像素几何；puzzles/screen画面；screen和screen-backing输入；raster-mask缓存实际遮罩像素，screen-apertures映射当前纸面；motion/screen有限过渡。数字纸带插值抽成共用小模块，晚邮与纸屏各自拥有动画，不互相套样式。窗口变化即使早于resize事件到达，也取消旧坐标中的手势。内容修订14保留正式旧档及本地13版合法开匣/半途输入，伪造标记不能得物。
