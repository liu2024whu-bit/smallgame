# 纸屏 · 旧版审查与下一轮设计边界

基线df814c9（V2.9.8）。本页记录尚未完成的P8，不把构想或旧规则可通关记为新关卡已制作。本轮先实际查看1440与390像素旧界面，并补充三位柱的[官方角色参考](v29-characters.md)。

旧版是九张角色卡各配一段折线，正背面仅换底色；图像与连接没有材料关系。电脑上勉强相接，手机上改成三行后，第三扇到第四扇的方向关系消失。画外“入口1→出口0”和小数字承担了玩法说明，线端很小；工具摇柄仅作进入门槛，没有实际动作。完成后两个奖品出现在通用领奖区，与纸屏本体无关。这些是已看到的问题。

现有9个二态元件有512种组合，全部接缝相连时唯一成立。保留这层推理复杂度有价值，但不保留它的卡片排布。正在比较的方向如下。

| 方向 | 观察与操作 | 取舍 |
| --- | --- | --- |
| 原版九卡三行 | 点击卡片，依靠数字连接 | 不继续；手机破坏邻接关系，画面与路径分离 |
| 连续的双面小纸屏 | 每片本身有两种图案，翻片后接缝位置变化；完整纸屏始终保持顺序 | 优先做原型；小屏须同时能辨端点、局部接缝与整体，不能只把长图缩小或藏在没有反馈的横滚区 |
| 三组彼此独立的小屏 | 每组三片，很适合手机 | 暂不采用；切断跨组证据、降低原九片的整体推理，容易变成重复三次的小题 |

三位柱的形象可以成为纸屏画面、装帧或可观察的图案，正式全名放在合适纸面上。水纹、风痕、白蛇等本作意象不冒充原作真实道具；画面留白与线索层级先成立，再选择角色细节。无需知道角色设定，也应能判断相邻与正反。

摇柄若保留，需要有可见轴、支点、传动和受阻依据，用于验证及带动实际变化；若材料关系说不通，应移除无用门槛，而非添加一句解释硬接。解开后先有可信的开合或露出，画页B与槽轮分别在原处拿取；未拿、只拿一件、全部拿走都需能回访与读档。P7和P8仍并行会合到放映机，摇柄不能因一次使用而被耗掉。

制作顺序为：先验证屏片/接缝在手机上的观察与翻动，再确定环境、远景和取物结构；以原收藏柜的木色、纸色、透视、线条和光照制作关键帧，放回整景比较后才扩展图层。自然图像承担主体与材料，不能拿大面积矢量折线替代绘画。文字、入口、出口与画面不冲突，提示只在主动打开时出现。

输入、有限过渡与纯规则分别实现。连续翻动的当前姿态、取消、失焦、缩放、键盘、撤销及减少动态需要实际操作；若增加开合状态则独立做旧合法进度迁移，不能让旧档被迫重玩或凭一个完成标记发物。后台与实际文字目录随选定版本同步，再完成本地、存档、下游和线上核对。以上仍是下一轮制作的验收边界，尚无新运行实现。
