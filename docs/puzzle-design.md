# 机关与探索

主线围绕四张画页与一本尚未装订的画册。故事是可以翻看的附页；所有规则、位置关系、正反面与机关状态都在游戏中给出，不依靠记住私人经历或角色冷知识通关。

## 主要约束

| 机关 | 思考与操作 | 回馈 |

| 往返校样 | 从示例推导翻面、循环位移、交换的组合顺序 | 透片；之后回访使用逆变换 |
| 两面的云 | 三个联动轮同时满足两面窗口，不能逐窗独立设置 | 圆镜与摇柄 |

| 胶片 | 花瓣先后→按时间执行翻页/跟随→终态，动作不能同时计算 | C页、孔数高度、第三条页序关系 |
| 花架 | 成对升降、真实上下限与正反转；书签固定一盆，改变成对移动约束 | 托板；原场景出现第二层用途 |
| 逆校样 | 根据结果逆推五枚印章的初始排列 | D页和针路 |
| 云景留白 | 拉动三条透片，负形投影同时对照三枚标记；与初次云景的转轮操作不同 | 四页顺序 |

| 装订 | 正反面交替的8孔连续路径 | 画册，打开生日里间 |
| 分糖 | 两条可移动细线把20枚图案分成四份，每份五种各一枚 | 收下可翻面的贺卡 |

| 生日匣 | 贺卡背面、可转孔带与旧圆镜叠合，四个窗口读出数字 | 正确密码拉扣开匣，两点烛光前的最后一份准备 |

排序、联动透片与分糖有唯一合法终态；缎带保留多种合法抽取顺序，密码锁也允许提前知道答案后直接试锁。迷宫允许两种等价朝向；天平允许左右互换；木框要求形状铺满且固定图案接合，不能把两块T形只因轮廓相同就互换。见 `tests/puzzles.test.mjs` 的枚举与见证路径。

## 角色与物件的用途

魈/流浪者的书签跟着书移动，是排序关系的锚点；九位柱进入折屏，翻面改变接缝；小黑、无限、鹿野进入有环境的胶片，花瓣与纸背动作承担推理；小王子完整画面成为拼图。带土/卡卡西进入创作角的画稿，两个独立柱角色亚克力砖作为真实收集物件。其中刻尺、镜读、邮戳、分拣格、孔带和胶片页边规则是游戏虚构，不是私人礼物本来就有的机关。

木书签用于取出纸盒、测距、固定花架与帮助装订；棉线用于云景牵引、轮组与缝页；圆镜用于背标与夹层；透片用于照光和云景留白；摇柄用于轮组、花架与灯座。各用途有场景对应，不消耗、不依赖随机试错。

两校折页以武汉大学老斋舍、南京大学仙林的杜厦图书馆与香雪海、鼓楼北大楼的公开实景为依据，只保留确认的名称与视觉细节。专业名称使用已确认的马克思主义原理，不虚构个人课程或校园路线。不会把“去过南京”变成“去过南大”，不编校史、学校关系或共同路线。邮戳放在折页的纸边，是虚构机关线索，不是校园现实编号。

回忆只保留一句锚点。回忆页和小记自愿翻看。十二项小记完成且看过生日页后出现彩蛋，任何小记都不会堵住主线。

## 引导层次

默认不展开玩法介绍。画面先给出可分析的目标、样例与物理反馈。操作可见：拖动物件、旋转按钮、接缝端点、正反面标记。规则线索在物件和同源记录中给出，手账保留关键关系；具体步骤只在自选提示的后两层展开。画面精简不等于隐藏点击区、要求猜开发者的意图或删掉必要前提。

## 反卡关设计

- 开场两件工具明确可见，拾取热区优先于后方台灯和稿盒，避免遮挡。
- 工具不损耗。手边可展开已有工具，允许拖到明确的物理目标，也保留点选操作。
- 前置不足时显示能继续探索的对象；完成记录会明确指向新可用的地方。
- 操作可撤销、可复位；完成的机关保留结果，手账保留线索。错误穿线和满孔失败仍可退回。
- 提示按“观察方向→关键关系→具体操作”三层打开，最后一层提供可执行解法。
- 不使用反应速度、长时间等待、听力或颜色差异作为唯一门槛；所有音乐盒线索均可视。
- 回忆和IP角色增加辨识与情绪，不构成需要联网搜索的知识锁。

## 试玩检查

先做不看攻略的PC试玩，记录真正停住的地点、是否误解操作与提示是否能解除卡点，再调整难度。自动通关只证明机制与依赖可走通，不等于已经证明与某一商业作品的玩家难度相同。

## 密码证据（实现核对）

数字锁：桥D1、树A4、雨B3、窗C2分别查分拣格，按锁面“桥、树、雨、窗”的次序得到1029，回应生日。南京片的反印可用圆镜照正。全部信息均可回看，不要求凭私人日期或校园常识猜答案。

字母锁：托板背面的列带为1、3、4、3、3，透片背面的行带翻正后为3、5、5、5、5。按Ⅰ到Ⅴ配对查询5×5字表，得到LXYXX：名字缩写与罗马数字20。两件旧工具再次提供线索，检查后分开记入手账；不要求猜缩写或懂罗马数字才能解锁。键入、选格、纠错、退格和回车走同一纯规则。

这两只锁都不在拨到正确值时自动开门，必须拉扣或回车。失败只产生回弹/轻响，允许继续修改；完成后冻结，不能重复发奖。

## 新生日桌

巧克力数字记录连续空位段，空位之间必须有巧克力。5×5行列段只有一组解，完成负形仍需要把最早获得的透片覆上；错误覆片可以拿开继续调整。提示例图直接画在纸边，不弹出规则课。

三只玻璃量壶容量8、5、3，初态8、0、0。每次只能倒到源空或目标满；目标是4、4、0，没有添水与倒掉按钮。杯形的4与4是可见目标，薯条旁的纸条保留“倒到空或满”的物件线索。全部可达状态守恒，最短解7次；拖动预览、取消、点击源/目的壶都调用同一规则。

生日桌不盘点送过的礼物。蛋糕、巧克力、薯条和未拆袋进入环境；米色Yummy小兔在结尾以后才可拆开，是本次准备的礼物。

## 生日准备台：取舍与交互审核

这三处保留在同一张准备台上，分别承担空间分配、遮挡推理和组合读码；不是三张相似图片套三个答题按钮。桌面进入近景后仍是同一个纸面和匣子。两条主分支可以往返，贺卡与纸带也能按不同先后获得；没有倒计时和一次性消耗。

| 审核问题 | 分糖 | 纸带 | 生日匣 |
| --- | --- | --- | --- |
| 为什么在这里 | 二十枚生日糖画在贺卡上 | 包装纸带遮着同一只匣子 | 纸带抽开后露出原先的字轮 |
| 怎样看出玩法 | 两根线、四碟五种糖的浅印；当前每份的重样/缺样可见 | 交叉处的覆盖与闭环/尾签，翻面能补足另一半关系 | 三处实物空位，贺卡反印、孔带星角与旧圆镜 |
| 怎样操作 | 直接拖线把手；方向键、Home/End也能挪 | 向外抽尾签或回车，翻盒后保留已拆部分 | 拖入或点放；可取回，卡片翻面、纸带转半圈；字轮拖动、输入、方向键与回车 |
| 误操作会怎样 | 保留当前分配，可撤销和复位 | 被压住的尾签回弹，不抽坏纸带；合法局部状态都能继续 | 错码保留输入，搭扣弹回；正确码不要求额外点击展示动作 |
| 怎样留下结果 | 卡片收进物品栏，远景与近景的四碟同步 | 抽掉的纸带在两面与远景同时消失 | 完整开匣状态画保留盒沿与衬纸，字轮保留实际密码 |

固定的二十枚图案枚举49个切分，只有一组满足四份各五种。纸带两面共9个实际交叉点，合法抽取顺序有4条，所有可达局部状态均可完成。贺卡4×4字与孔带按同一单元坐标渲染；星角朝向改变真实孔位。四孔借圆镜读作2006，回应20岁，不需要额外猜私人年份。

房间只记录谜题完成与实际物件，不用“看过提示”或“点过某页”解锁。未完成旧存档可继续完成新增准备；已经看过生日结尾的旧存档保留结尾，不自动补领贺卡与新小记。
