## 更新路径

点击按钮 → `app` 分发动作 → `state.reduce` 检查前置与动作 → 对应纯规则更新 → 检查完成条件 → 派生物品与可访问机关 → 保存并通知视图。

每个规则对象提供 `create / valid / move / solved`。规则不读取 DOM、音频、存储或时间，不改变传入状态。胜利后状态冻结，避免重复发放物品。回忆呈现与小记独立于谜题结果。旧存档中的服装字段只保留兼容读取，当前没有换装界面。

拖动期间只有临时预览，抬起指针时才提交一个合法动作，因此一次落位对应一次撤销。Esc、窗口失焦、指针取消、关闭或重绘弹窗都会释放会话和浮动图。连续描线提交原子节点序列，若含非法跳跃则整笔拒绝；密码必须试锁成功才完成，错误输入保留字轮。重排提交索引变化，画页身份与正反面不分离；拖动与原有按钮走相同的纯规则。

物品由“拾取记录＋已完成机关的奖励”派生，不维护第二份可能失配的背包数组。工具不消耗，花架完成后自动释放书签。透片和托板通过数据映射关联各自背面线索，检查后分别记入手账，字母锁继续使用这些旧物件。机关可以返回、撤销与复位，因此没有把关键工具永久留在错误位置的情况。

存档格式版本为2，内容修订号为4。migrations先按旧依赖验证旧完成记录，只在旧版相应下游确实完成时补上新门槛的合法完成状态。部分进度只迁移已经越过的门槛；伪造solved或缺工具的记录不迁移。规范化后按定义顺序整理完成项，重复读写结果稳定。仅恢复已知场景、合法规则状态、确认过的工具和设置。完成声明必须同时满足真实胜利条件和依赖；导入一个写着 `solved` 的对象不能直接领取画页。读取失败时尝试上一份有效备份。存储被浏览器禁用时继续允许游玩与导出。

`smallgame:v2:room` 与 `smallgame:v2:backup` 是仅有的两个写入键。不清空整个 localStorage，不覆盖 V1，不上传进度，不加入分析服务。

`activities` 仅保存白名单中的可选互动标记；`discovered` 保存已翻看的收藏组。旧V2缺少这两个字段时按空数组读取。14件可选小物始终从真实拾取和胜利结果派生，不能靠浏览画廊获得。小记资格集中计算，不保存另一份“已完成成就”数组，也不向谜题规则写完成标记。

## 画面、动作与声音

场景是一幅完整的栅格画，热区只定义交互位置。收藏柜的画稿与立牌绘入场景，不使用白底人物图覆盖家具。需要拾取的物件使用透明精灵，拾取后消失。

机关界面中的 SVG 只画可操作线路、迷宫轨道和图标。物件与角色来自本地 WebP；精灵图的尺寸和非等分裁切框统一放在 `asset-layouts.js`。CSS 变量使用绝对解析的同源 URL，兼容 Pages 子目录。

动作层测量更新前后的物件位置：交换校样、书本、胶片、画页和花盆有连续位移；轮盘沿最近方向转动，棉线与针路逐段显现。物品栏只对新获得的物件播放拾取动作。焦点、滚动和工具不会随动画丢失。系统减少动态效果设置与游戏开关均被尊重。

声音由 Web Audio 现场合成：低音量原创和弦、纸张摩擦、木质轻响、玻璃音、机械键声、字轮轻响、雨声与六音音乐盒。第一次点击后才建立音频上下文，关掉声音仍能完成所有机关。雨声在离开对应面板、静音或切到后台时停止。没有使用原作配乐。

## 扩展方式

添加机关：新增纯规则与视图，在 `data/puzzles.js` 注册前置、工具、奖励和三层提示，再添加场景热区。先用合法控制序列证明可完成，涉及约束的机关应枚举或搜索可行解。

添加回忆或画作：修改对应数据与本地资产清单，不在控制器里塞特例。未知回忆不预填，未经授权的个人材料不进入仓库。变更存档结构时提升版本并写显式迁移，禁止把旧存档当成新结构直接读取。

修改已有功能时优先替换其规则/视图/数据；删除功能时一并移除入口、样式、无引用素材和检查声明。只有向后兼容的可选字段可以在V2中补默认值；破坏性变更才提高存档版本并迁移。艺术、交互和规则分别修改，禁止为了单个新画面在app里叠加一套第二进度系统。

## V2.3 的场景与物件

`core/exploration.js` 集中派生开放视角。雨廊依赖借光，画桌依赖花架，生日桌还要实际使用摇柄。`usedTools` 只保存通过工具持有和前置条件验证的持久放置；它不复制背包和谜题进度。按钮、物品栏拖放、机关手边工具都通过同一 `useTool` 和纯规则。

`data/scene-changes.js` 以真实完成记录派生局部绘画变化。每一块蒙版包含整个物件与柔边，一块源图可以承载多处变化，但不会提前显示另一处未解开的机关。收藏柜里的六槽音乐盒、迷宫轨道再复用近景位图和规则数据，避免远景生成的近似槽数与实际机关矛盾。花架的远近景使用相同植物、升降轨与最终高低。

`data/mechanism-layouts.js` 记录音乐槽、针孔、抽屉、翻片的原图坐标。布局按源尺寸归一化，不能用固定视口坐标凑位置。`ui/interactions/music.js` 只提交完整音钉落位；`ui/interactions/maze.js` 处理直接转环、取消与临时试路，试路不修改答案或存档。`mazeTrial` 只沿当前真实边走，抵达出口即停止，枚举测试覆盖全部216种朝向。

花架视图从已经完成的胶片顺序读取孔位纸条，不另写一份目标常量。书签只改变固定位置，摇柄继续走同一个联动规则；插拔、平台移动与提示邻盆是呈现反馈。新巧克力和倒壶规则独立维护：拿放一笔为一个动作，倒壶守恒，覆片由旧透片触发。

开场介绍只用于无障碍标签。画面保留操作区、刻度、目标、例图与物件线索，自选提示仍有三层。机关完成区不再附上个人回忆或自动展开长段解释；线索和少量回忆留在手账。未拆生日袋在结尾以后才允许打开，文案只写本次准备的礼物。

## V2.4 的交互与呈现

动作协调器只负责调用四类驱动的 capture/play。物件位移、机械转轴、纸面翻转与字轮、液体与材料动作各自测量、各自过渡。旋转与纸张翻面使用物件身份匹配；重排中的纸页不会被误当成另一个翻面对象。系统减少动画与游戏开关都在动作入口判断，完成后的自动滚动也遵守同一设置。

重排时先预留落位空间，保存状态仍在松手后一次提交。拼木片记录被抓住的图案身份，R旋转后把同一格留在手指下面；从木片盒或拼框内拿起都遵守此规则。天平的实际盘内摆件也可再拖，原托位只留下淡影。四格抽屉的拉/推动作与点击使用相同纯规则。迷宫SVG触摸环使用稳定焦点键，连续方向键操作不会跳回关闭按钮。

校园站点与实物手账排布分别在 data/campuses.js 和 data/record-display.js 维护。仙林的实际建筑依据公开照片；书桌是游戏虚构。拓印的笔画和覆盖网格仅存在当前指针会话，达到覆盖条件后保存一个 campus:desk 活动标记。取消一笔不计覆盖，关闭后不保存半张拓纸；已拓好的结果可在旧的活动白名单机制中恢复。没有增加第二份谜题进度或成就完成数组。

小记资格继续由核心模块派生，呈现改为11件纸上小物；移动端在两页之间翻看，避免把整本缩成不可读的缩略图。彩蛋摇柄的孔位和精灵转轴使用同一份测量数据。上弦、拆信等临时状态保存在面板view里；关闭后可重新操作，不改变主线。新增内容是可选活动，不增加主线门槛，存档版本2与内容修订4保持兼容。

## V2.5 的连续操作

dialog-state.js集中记录当前阅读位置、稳定焦点和有键的details展开状态。打开子面板前把快照放在原面板对象上，返回时恢复；它只存在导航栈，不写入存档。点击空白边缘不再等同于点击遮罩；只有从遮罩开始的一次真实点击才关闭窗口。

pointer.js继续保证一次手势一次提交。旧拖动只抑制它自己产生的点击；新的按下或键盘激活会解除旧抑制，不必等待350ms。取消浮动图的归位仅是视觉副本，按动画结束或短超时清理，不延迟规则提交。

sweep.js用线段与矩形交点排序，补上两次指针事件之间经过的轮心、针孔和巧克力格。穿线回退只移除本笔临时增加的节点，已保存的路线仍经原有纯规则与撤销处理。没有加入第二份答案或绕过规则的DOM进度。

反馈短句在data/feedback.js维护，约束和三层提示仍在data/puzzles.js。错码反馈比较实际试锁次数，不随编辑字轮重复播放；音乐预听绑定到当时的机关元素，离开或改音钉会停止。新开放视角在开放时预载，避免只在启动时缓存最初四景。


## V2.6 的生日分支与近景

新增sweets、ribbons、birthdayLock三个纯规则模块，主线共19处、独立机关仍6处。生日门内可以先分可可，也可以先去准备台；分糖和拆纸带彼此独立。新结尾要求可可、贺卡和生日匣都已完成，旧ending通过原有显式迁移保留，不伪造新关卡完成记录。内容修订号为5，存档版本仍2。

data/birthday-workshop.js集中保存二十枚图案、双面纸带路径、叠放顺序、孔位、印字和源像素矩形。纸带阻挡关系由两面的实际交叉点计算；印字与开孔使用相同单元中心。ui/workshop-props.js负责同一物件在远近景的坐标换算与精灵；准备台使用原3:2比例，不能拉伸成旧房间的16:9。

PUZZLE_TOOL_INPUTS声明可嵌入的物件，核心层校验真实库存。导入时先重建依赖与物件，再移除伪造的嵌入状态；正常部分放置可保存、撤销、取回，工具不消耗。app.useTool用数据映射分发，不继续增加按机关名判断的分支。嵌套投放区按被拖物件选择匹配的祖先目标，纸带先放好时仍能把贺卡放到它下面。

密码锁的数字与显式拉扣是开锁条件。卡片翻面、纸带朝向和镜子用来显露证据，不作为隐藏开锁门槛。即使先猜中密码，贺卡仍可独立完成，生日桌按自己的准备条件汇合。小记新增一张卡片，完成数从solved派生，不另存成就状态。

workshopMotion按前后状态处理抽带、翻盒、放置和开匣；机械旋钮共用最短弧收拢，迷宫轨迹按实际路程分配时间。减少动态效果时这些驱动统一跳过。手机近景的缩放、内层平移和子面板返回位置只在view及dialog-state中维护，不写进谜题状态。


房间切换由services/room-transition.js统一接管，替换原来的CSS入场淡入。相同比例的画面在新图解码后交叠220ms，不同比例只淡入新画180ms；快速转身移除旧过渡，不积累图层，热区不随过渡移动。配合原有对话框短淡入与独立材料动作，避免两个系统同时动画同一份背景。
