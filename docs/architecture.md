## 规则与保存

界面动作 → app协调 → core校验前置／工具 → 纯规则 move → solved → 开启取物来源和可访问区域 → 实际pickup → collected → 保存与视图。

规则只提供 `create / valid / move / solved`，不访问DOM、音频、时钟、存储或随机数，不修改输入对象。机关完成状态冻结；拾取单独验证来源和未领取，避免重复发物。19个主线机关、7个独立机关共用这条路径；独立机关不进入生日门槛。

库存只读取collected；解开来源后可领取，实际pickup才加入，不再从胜利奖励自动生成背包。工具不消耗，可放置、取回与多次使用。嵌入状态必须有真实库存支持；输入正确的密码并拉扣即可开锁，不把“是否读过说明”作为隐藏门槛。

拖放期间只画预览，抬起才提交合法动作。一次落位对应一次撤销；Esc、失焦、取消、关闭及重绘释放会话与拖影。连续描线提交完整合法路径，原路回走可以退回；非法跳跃整笔拒绝。按钮与指针调用同一规则。

字轮与字母输入按真实焦点定位，键入后前进；只有字格／机关本体的Enter直接试锁。方向按钮上的Enter保留原生按钮行为。弹窗先聚焦标题，返回恢复原控件、滚动和放大位置。

存档格式2，内容修订11。迁移重建真实依赖，只为已经跨过的旧门槛补合法状态，不凭 `solved` 声明直接发奖励。修订9以前验证通过的来源恢复原来自动发放的物件；修订10起保持已有物件的未领取/部分领取。新借阅签仅为修订11以前已经通过验证的邮匣来源补发，修订11保持开匣未取；很早版本已走过书架的合法路线也继续通行。新增日历默认未完成，旧结尾仍可读；规范化可重复执行且结果稳定。偏好枚举、音量、动作、场景、工具、活动均校验白名单。

正式进度只写 `smallgame:v2:room` 与 `smallgame:v2:backup`；不清空整个localStorage，不覆盖V1。读取损坏时尝试有效备份；保存被禁用仍能游玩与导出。确认重开后先成功写入新进度，再删除旧备份，保留设置与音源。

活动仅保存可选互动标记；小记资格从实际物品、机关、活动派生，不保存第二套成就完成表。14件收集物不会因浏览后台画廊自动加入正式进度。

## 画面与动作

场景为完整栅格绘画，热区只定义交互。绘入家具的角色和小物不再覆盖白底人物卡。精灵的解码尺寸、非等分取框、脚下锚点统一放在素材数据中；保留原比例与完整本体。

谜题轨道、开孔、数字和图示由真实规则的数据绘制；不是把参考截图作为不可交互按钮底板。近景与远景使用同源部件和完成状态，字轮、糖、带、音钉、迷宫和平台同步响应规则。

换景保留上一幅实际可见绘画，包括完成后的局部与原生微缩部件，等新画解码后短暂交叠。不同构图比例不拉伸旧画，快速转身取消旧层。热区直接处于终态，不跟背景漂移。

小黑用原有眨眼与新增六张过渡姿态，按脚下位置切换和短交叠；点击中断只保留最新动作。猫狗直接抚摸只改变临时近景姿态，首次完成手势才记活动。背景与家具保持稳定，不通过拉伸整张画制造呼吸。

花架几何集中于data/garden.js，近远景透视分别标定，规则高度和制动状态共用。garden动作模块独占平台、摇柄、书签与完成窗光，原通用花盆/书签处理已删除。

光影关卡的灯、器件、透片印花、参考、投影和纸稿全部使用栅格原画。SVG仅提供自适应视口，没有可见路径；CSS裁切只限制纸面、镜口与遮挡。四角变换按真实反射投影计算，测试还对照内部着色点，避免只对齐四个角。木片和下垂的穗子分别取景；世界坐标、素材坐标和相机数据共用，近远景不另存进度。

放大焦点由视图数据提供，首次进入才定位；已有滚动位置继续保留。有限的靠近/退远变换只改变呈现，禁止写入规则或存档。

每类材料有自己的有限动作驱动；系统减少动态效果或游戏关闭动画时结束有限过渡、停止循环装饰。装饰动画不掌管规则和交互结果。机器性能仍会影响实际帧率。

## 文件导出

文件名包含小屋名称和实际保存时间。优先使用原生选位置接口，write和close完成才显示存好；取消不启动第二次下载。接口不可用时用UTF-8 Blob命名下载，URL保留15秒供浏览器接手。回执显示文件名与寻找方式，不编造不可获知的系统路径。最近文件名与进度分开，演示不写正式记录。

导入先检查大小、JSON与版本，兼容UTF-8 BOM，再由core重建真实依赖。失败保留原进度。音频、维护解锁和演示临时状态不进存档。

## 音乐

所有本地录音、Blob与官方公开源共用原生Audio适配，避免跨域WebAudio图导致在线音源无声。`music-player` 持有加载序号、意图、源版本、AbortController和失败会话；music-decks管理当前与淡出声部。过期结果立即释放，寻位／切歌／离页清理媒体、计时器和对象URL。播放启动、metadata、seek与卡流有可取消期限。新曲真实可播放才交接，失败恢复旧曲；普通解谜操作不重试已经失败的源。

`deck-fade` 单独拥有音量变化，平滑交叠可中断。物件声仍经WebAudio；首次指针或键盘操作解锁，页面载入不提前出声。花架与图章音色由foley独立负责，不写进规则；试听压低背景音乐。切后台暂停，回来按偏好恢复。music-view局部更新唱片、唱臂与进度，纯音频偏好不会重建正在拖动的谜题或唱片DOM。唱片角度是表现状态，实际寻位只在释放时提交，取消不改变音频位置。

许愿的生日歌属于临时插曲，不改用户选择的曲目；播放完恢复前一首的实际位置。静音、音乐关闭、后台和插曲失败均有回退。五份本地音频可直接听，六个公开在线版本已准备；《无人知晓》播放明确标注的Fayeii翻唱版，并另留田馥甄原唱入口。不绕过平台权限。同一ID换录音也会更新源版本。

本地文件存于独立 `smallgame-audio / tracks` IndexedDB；持久写失败可在本次会话使用并说明，不上传、不随存档导出。删除本地覆盖后仍保留原在线源；失败不谎报成功。服务器支持206/416及后缀字节范围，原生Audio可真实寻位。

## 维护与文案

维护入口摘要验证固定PIN，仅用于防误入。它无法保护公开静态文件，不加入账号、密钥或伪服务端登录。

真实游戏通过 `mountGame({storage,library})` 注入存储；正式入口用浏览器保存，review-frame只用内存Map和内存音源库。演示夹具按真实 reducer 与验证走法重建，经 core 规范化后才展示，不给正式入口加作弊参数。

邀请步骤与设置子页按真实DOM/当前view映射后台位置；指针外观偏好独立布尔校验，不改变进度。导航复用renderScenePicture，把固定源空间的字/物件一起缩小，ResizeObserver在关闭时断开。

后台目录覆盖机关三种状态及收藏、物件、证据、校园、祝福、小记、故事与系统回应。侧栏从当前可见DOM读取文字和来源编号；实际在演示里继续导航时，文字所属页面也跟着切换。全量导出按同一目录逐页渲染，隐藏面与主动提醒不会混入初样。

维护会话解锁只存sessionStorage标记。重锁销毁演示iframe、监听器和页面接口；不改正式进度与备份。QA使用独立浏览器上下文，测试存档与截图不放进发布入口。

P5的透片在物品栏、检查、P3奖励、P5和P17共用同一材料与图形；固定黄铜框属于支架。圆镜以原黄铜花纹柄为准，不因近景重绘换材质。逐件状态见[v29-prop-continuity.md](v29-prop-continuity.md)。

P6的镜读使用同一张邮片印刷层的负X映射和有限圆形视口，观察姿态只在panel.view中，不存进规则，不以看过线索为开锁门槛。这是一处平面镜读呈现，不声称建立了完整三维反射模型。近远景读同一进度与collected；字轮拖动只预览，释放时提交一次。共用数字输入仍保留日历/生日匣原来的档距和绘制路径，不能因本关变更而丢掉其他机关的数字。

可见文字导出同时检查隐藏面与硬裁切视口；滚动区域中的自然长文仍会保留。镜外印刷与轮外重复数字不会混入当前可见文字。实际演示录像来自鼠标操作，静态多版对照不加载旧运行代码。

P7的order/fitted/opened/attempts是唯一规则状态；查看哪本书、纸签哪面属于临时panel.view，不要求读过线索。抽屉预览不发库存，打开后才生成可拾取按钮。内容修订12保留合法旧完成与部分排列，不认可独立伪造的solved字段。

四份光遇人物由sky数据与sky-figures按实际帧区、相对高度和原比例复用；不同取景只给物理高度与所在平面比例。没有保存第二套服装进度或复制每页角色图；换组动效是独立有限所有者，减少动态由共用收束器处理。

触摸补点继续只负责补发与去重，不代管机关含义。补发事件现在保留实际松手坐标、触摸类型和原指针；不能使用丢掉坐标的HTMLElement.click()，否则同一纸片的实心/镂空会被错误解释。
