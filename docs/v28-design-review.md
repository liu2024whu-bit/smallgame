# V2.8 体验审查

审查顺序为“看到线索 → 判断可做什么 → 操作 → 反馈 → 回访”。本轮用空存档实际完成全部26个机关，再检查后台218种页面状态的桌面、手机与清晰字体布局。规则验证、自动操作和玩家盲测是不同证据，未据此宣称已达到其他商业游戏的难度或制作水平。

## 文字与界面检查

218处包含初样、完成、主动提醒、物件正背、两校折页、小记、花与系统回应，导出自实际DOM，见[文字检阅](copy-review.md)。修改以该编号与来源为准，不建立第二份手写文案表。

桌面、390像素及320像素检查了横向溢出、标题盖按钮、控制越界与被裁掉的可见文字；清晰字体另查桌面和390像素。小屏新发现的云景控制、纸背箭头及薯条近景均已修正。像素检查只能证明边界与布局，不代替对每幅画的审美判断。

保留的实际限制：静态维护密码不保护公开代码；平台原声受平台权限影响；角色新绘的识别度仍需用户目视反馈；自动见证路径不代替玩家盲测。未追加未经证实的个人故事来填满画面。
