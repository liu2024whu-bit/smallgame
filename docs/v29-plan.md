# V2.9 持续改造：要求、审查与完成条件

目标来自本次持续目标及本聊天前面的要求。它是工作记录，不作为游戏内文案。基线为a039397（V2.8）；“自动通关”只证明路径可达，不等于审美、玩法可读性或手感完成。

## 逐项完成的方法

每个项目按同一闭环推进：保存当前可玩基线 → 实际观察问题 → 画出玩法/状态/道具关系 → 至少两个可比较的可玩调整 → 选择并清理被替代实现 → 鼠标、触屏与键盘操作 → 检查前后场景及存档 → 更新演示和证据。小修不为凑版本复制代码；迭代对照放在review中，运行代码只保留选定方案。

完成标准不是“加了什么”。需要回答：看到什么证据、能猜到哪些操作、如何验证假设、失败后怎样恢复、完成后什么改变、旧道具还有没有合理用途。引导随情境出现，主动提醒不成为隐藏解锁条件。

## 素材与动作准备

每个项目在绘图前先列出可见状态、动作与输入，明确需要修改原图、拆分图层、补帧还是只做变换。跟随本表逐关落实，不能因为制作新素材而跳过旧界面、文案、存档和玩法的检查。

- 场景分为固定环境、可移动物件、遮挡前景和完成变化；同一相机保留透视、纸色、阴影方向。远景与特写使用同一份规则状态和坐标依据。
- 动作先做接触/起势/途中/落定的关键帧，再补必要过渡。毛发、眨眼、转头等形变才补画帧；平移、旋转、开合由图层与时间插值完成，避免每帧随机重绘造成闪烁。人物固定脚下锚点、物件固定支点，贴图边缘留足安全区。
- 每组帧记录来源、尺寸、帧区、锚点、时长、播放条件、结束状态和减少动态时的静帧。只预载当前场景及紧邻的解锁场景，验证首屏、解码与切场等待；完整动画不会成为解谜的等待门槛。
- 重绘先从已经接受的场景和官方造型参考出发，不使用私人照片或信件。每组先检查一张关键帧的比例与风格，再制作同组素材，避免大量生成后才发现方向错误。
- 指针归入P2统一交互：小尺寸柔和卡通造型，默认、查看、抓取/拖动和可使用各有轻微区别，热点准确，不遮挡线索。仅精确鼠标启用，触屏不显示；输入框保留文字光标，系统高对比与不支持自定义时回到原生指针。不依赖光标作为唯一提示。

各项目完成时同时复核全局要求；新增帧或特效必须说明它改善的动作，不以图片数量作为质量指标。
