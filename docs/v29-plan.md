# V2.9 持续改造：要求、审查与完成条件

目标来自本次持续目标及本聊天前面的要求。它是工作记录，不作为游戏内文案。基线为a039397（V2.8）；“自动通关”只证明路径可达，不等于审美、玩法可读性或手感完成。

## 当前持续目标：逐项落实与整体验收

持续完成这款生日独立解谜小游戏的整体改造，使玩法、画面、叙事、操作、声音和系统协调成一部完整作品，并交付经过真实浏览器核对的可玩版本、对照演示和可修改的文字目录。目标保持进行中；未完成的关卡、已发现的审美问题或必要验证不能用“代码运行正常”“全程可达”代替。此前完成的部分是可回访的基线，新的全局要求同样适用于它们。

每次恢复工作先回顾本目标、全局约束、已确认事实、最近反馈和当前项目证据。新增反馈写回对应条目，判定它是全局要求、局部问题、已确认事实还是可选建议，再检查影响到的相邻场景、同类物件和下游使用；不能做完新内容便忘记旧内容。

### 1. 先解决设计问题，再决定增添、修改或删除

- 每关先说明玩家能看到什么、可以尝试什么、证据如何支持推理、如何验证与恢复、完成后哪里改变。观察实际旧版，保存问题证据，整理场景、谜题、道具、线索和结果之间的关系，再制作候选方案。
- 对重要问题做可比较的多轮迭代，逐轮实际操作并记录取舍；不是只换配色，也不为凑版本复制整套运行代码。新谜题只有在增加有意义的观察、推理或道具关系时才加入。
- 选定方案后替换旧视图、输入与美术注册，确认没有引用再清理过期代码和素材。不要用越来越多的覆盖规则、条件分支、补丁图片和重复状态维持旧实现。
- 一个部分完成必要的设计、制作、操作、存档与下游核对后再推进下一部分；发现全局问题可以回访已完成部分。不同项目的现状和下一步保持明确，不把“做过”记成“已验收”。

### 2. 原有画风是新素材的约束

- 延续已经接受的原场景：温柔、雅致、轻松的手绘气质，协调的纸色、木色、笔触、线条轻重、纹理密度、对比度与光照。新物件必须放回整幅画里判断，不能只看单件大图。
- 与场景中同类物件直接对照：新书与原有书的装帧、厚薄、颜色、纸口和轮廓应属于同一世界；木盒、花盆、金属件、纸张、灯与家具同样处理。不能为了放字把书画成厚礼盒，或靠装饰和滤镜掩盖材质不合。
- 角色优先依据官方原画、实际造型或可信文创资料，再做适合整体画风的呈现；不把重绘作品称为官方原图。不凭印象改发型、服装、面具、身高和角色身份，不反复用同一张角色图充场。
- 采用自然栅格画面表现主体与材质；尤其光影机关的灯、夹具、透片、目标、投影与纸稿保持自然图像，不以可见矢量线条代替画面。必要的接口图标和逻辑符号承担清楚的交互用途。
- 生成或修图先确定关键帧、材质与相机，再扩展同组素材。减少明显的生成瑕疵、假字、无意义纹样、过亮金属、厚描边和重复细节；质量由成片和体验判断，不以图片数量判断。

### 3. 每一层图像都要有空间依据

- 从原场景确定相机方向、视平线、物体尺寸、地面或台面的承托位置。核对可见的顶面、侧面与正面，书脊、层板、桌沿和抽屉的走向要相容。
- 检查落脚处、接触阴影、投影方向、阴影软硬、遮挡前后、边缘颜色和透明区；不能悬空、插进家具、露出白边、让背景透穿实物，或用错误图层盖住本应在前面的东西。
- 远景、放大、背包、安装、抽出、翻面、复用与完成状态属于同一件物体。近远景可以采用不同相机和绘画，但要保留轮廓、装帧、材质、附件、比例和所在位置；不能简单把整张近景面板缩进家具里。
- 拖动与开合先有正确的承托、支点、轴线和轨道，再做动画。抽屉向合理的方向伸出，里面的纸、针、钥匙等放在实际底面；解开后的图层要与仍未破解的邻近机关兼容。
- 图片和图集按实际本体重新注册，不沿用重绘前的取框。核对头发、衣摆、手柄、纸边、穗子与小零件完整，不拉伸长宽比，不混入邻件；装饰和触区也不越过不该越过的边框。
- 同一套核对适用于所有场景、原先已修改部分与后续新增部分。既查看静止终态，也检查转场、移动途中、错误反馈与完成动画；截图等待必要的解码和转场落定，不把中途交叠误判成静止缺陷。

### 4. 难度来自观察与推理

- 参考绣湖、HER TREES和拣爱末段机关的观察、关系转换与发现感，形成自己的玩法。难度可以复杂，但每个必要步骤必须有可观察、可分析、可验证的依据。
- 形式保持变化：空间、顺序、正反、投影、遮挡、密码、材料、音高、时间或组合等服务各自场景，不把所有关卡做成贴图加按钮、同类排列题或反复点击。
- 密码机关应是真正可操作的字轮、输入或锁扣；生日和相关日期可以参与密码，但读法要在游戏证据中成立，不要求记住私人经历，不凭空猜日期、年份或字符。
- 线索可以藏在找到的物品、夹页、背面、图案、场景变化或多个物件的组合里。观察姿态和“读过提示”的旗标不成为隐藏通关条件；知道并推得答案的玩家可以正常验证。
- 谜题主线可以并行、会合、解锁新场景并回访旧处。明确一对一、一对多、多对一和多对多的关系，不强制一直沿单一路线走到底；可选的小机关和成就不无端卡住生日结尾。
- 指引随情境出现，优先由构图、材质、运动和反馈让人理解操作。主动提示分层、可选、简短而自然；既不直接泄题，也不让玩家因不知道能拖动或目标在哪里而无从下手。

### 5. 道具、结果与操作形成完整手感

- 道具能自然拿起、拖到合适位置、安装、取回、组合或复用；无效操作有轻微且明确的反馈。不能为了进度而设置没有材料用途的工具门槛。
- 破解与领取分开：盒、门、暗格、抽屉、环境或新场景先发生实际变化，物件留在可信的位置，玩家实际拿取才进入唯一库存。未拿可回来拿，拿走后不重生，部分领取也能保存。
- 拖动保留抓取点，过程跟手，放置区公平，吸附和无效预览清楚；旋转、拨轮、插拔、拼图与连续穿线分别打磨，不用点击替代本应自然的物理操作。
- 鼠标、真实触屏和键盘各自核对；小屏重新取景和安排触区，不把桌面界面整体缩小。新增主要触区以至少44像素为基准，文字与实际命中位置一致。
- 一次连续操作只生成一次撤销。Esc、失焦、手势取消、拖到场外、关闭、切换视图和尺寸变化后不误提交；没有残留拖影、点击穿透、触屏重复触发或焦点丢失。
- 已破解机关有明确而协调的终态，可以回看必要证据和取未拿的道具；再次进入、下载重读与返回远景后都与同一进度一致。失败、错误尝试和不同合理顺序都不能造成软锁。

### 6. 动画与声音服务具体动作

- 进屋、靠近、退远、翻纸、抽看、开盖、拨轮、取物、解锁和换景采用适当的连续过渡，动作有起势、接触、途中和落定，结束位置准确，不让玩家等待无意义动画。
- 刚体移动由正确的图层和插值完成；角色眨眼、转身、抬爪、毛发和衣物等形变按需要补画连续帧。脚下、关节和持物锚点稳定，不用拉伸整张图冒充动作。
- 有限动作使用单一动画所有者，快速再次操作、中断和离开能正确收束；系统或游戏切换减少动态效果时立即落定到可操作状态。检查低端、小屏和素材解码下的流畅程度，不虚报帧率。
- 纸、木、金属、转轴、脚步、取物、失败、成功、猫狗和环境按实际动作配合适的声音；音量、静音、节流和BGM关系协调，不用同一种音效覆盖全部机关。
- 歌单覆盖用户指定曲目及生日快乐歌，逐首确认实际可播放版本、载入、暂停、切歌、寻位、循环、失败恢复与生日插曲返回。优先合规可用的指定录音；不能取得时明确版本、采用适当公开版本或本地导入，不冒充原声，也不绕过付费、账号或技术限制。

### 7. 故事、喜好与真实事实自然出现

- 保留有名字的开始界面、20岁生日献词、简短前置小剧情、可探索的过程中故事和自然结尾。回忆只需让人想起，不替她详细讲述往事，也不把所有礼物逐件盘点。
- 文案使用自然的简短词句或完整自然段落，可以温和调侃、略微抒情；避免命令式、指使式、干巴提示、模板鸡汤和工程术语。标题、按钮、说明、错误、提示、成就与设置都逐一审核。
- 字体按载体区分：书脊与印刷书名采用适合装帧的印刷字体，夹页和便条采用克制的手写感，界面操作文字优先清晰一致，字轮数字强调辨认。开始标题可以有独立的艺术字设计，正文和辅助信息保持阅读节奏；字体、字号、字距、排列方向、缩放与原画同时审核，不把所有文字套成同一种风格。
- 文字的位置、字号、对比、行长、标点、背景与手机换行同时检查；不压住人物、关键图案、数字、物件边缘或交互区，不把隐藏的一面导出成可见文字。
- 光遇、带土与卡卡西、魈与流浪者、罗小黑战记Ⅱ、小王子、猫狗、花、两校意向、生日蛋糕、巧克力、薯条等按合适的场景与玩法融入。可作为线索、道具、环境、短剧情或可选收藏，不机械堆满每一关，也不强求每项建议都做成独立系统。
- 角色服装、面具、身高、发型、斗篷、校园与专业、两校吉祥物、日期、农历表达、风铃、分开的亚克力砖和未收到的小兔等，按下表已确认事实执行；未知经历、同行、校内路线、课程、年份和其他礼物细节不编造。真实个人叙述与虚构游戏机关分清。
- 私人信件不读取、上传或引用；其他私人资料不因制作游戏而自动获得外发授权。素材请求、检索、截图、文件名、文档与发布均检查隐私，使用原创或本地脱敏素材。

### 8. 完整系统、收藏、小记与彩蛋

- 开始、继续、介绍、设置、音乐、返回、结尾和后台形成清楚的完整流程。按钮、图标、光标和界面气质与原画协调，星月、彩虹、花或角色只在合适处点缀，避免统一硬卡片或按钮墙。
- 设置涵盖合理的声音、音乐、画面、动态、清晰文字、交互辅助、全屏与进度选项；实际开关生效并能恢复，手机和键盘可用，不把开发信息放进玩家流程。
- 非解谜互动可以进入有内容的小记、收藏与成就，每条有合适的简短介绍和不同的发现、展现或回访动作。条件由真实活动派生，后台浏览不代领；全收集有独立、用心而不过度解释的彩蛋。
- 存档要真实可下载、找到文件并导入：支持时选择位置，降级时给实际文件名和浏览器下载记录说明；在独立空环境读回半途、解开未取、部分取物和完成状态。坏文件、取消和失败不覆盖好进度，旧合法存档可继续，测试存档与正式进度分离并及时清理。
- 后台沿用指定口令，只作为维护入口的防误入措施，不称为服务器安全认证。可以查询、跳转和操作全部关卡、物件、场景、系统与变化状态；正式入口不暴露演示接口，后台不修改正式存档。
- 从实际界面导出可见文字、位置和来源，包含需要展开或翻面的页面，便于用户修改。提供旧版、候选版、选定版、手机、远景与真实操作演示；说明夹具、真实新开局、录像配音和验证范围的区别。

### 9. 清晰架构、资源和验证边界

- 维持静态原生ESM与相对路径：纯规则不访问DOM、音频或存储；core拥有唯一进度与库存；内容、证据、素材帧区、场景坐标、渲染、输入、动效、音频和保存各司其职。新旧实现有明确替代关系，避免重复状态、答案常量和无穷增长的处理器。
- 外部工具、CSS、动效或技能只在有具体收益时采用，优先可信原作者、明确许可与可维护资源，复用已有副本；需要下载时按约定放在指定资源目录。不为展示工具使用而新增依赖、安装或复杂框架。
- 验证与改动相称。必要的规则枚举、依赖与存档测试、源文件与素材检查、真实浏览器操作必须完成；测试通过后只因新改动、失败或未解决问题扩大或重测，不机械重复。
- 每次发布检查变更、过期实现、隐私、图像元数据、下载文件清理和项目结构；发布后确认构建与线上加载、实际输入和恢复。不能用本地成功代替线上成功，也不能用测试夹具或自动路线冒充完整体验验收。

### 当前优先顺序与停止条件

光遇回访已按佩戴模型重画正太、经典巫师帽、樱花头与两类面具，机关、房间、画册、收藏与目录共用四份纸人；两份旧运行图已移除，完整轮廓、相对身高与切换实操已查。它们仍是风格化重绘，保留后续目视修正空间；童真面具不混作矮人面具。字体载体区分与开始标题的艺术性继续列入P2回访，不能因书脊换了字体便宣布全局文字完成。

国产作品优先查国内官网、认证官方账号、角色展示和宣传片。核对出处同时记录时期、版本、地区与衣装；旧测试页与新版不一致时保留差异，不把早期资料直接当作当前设定。实际确认、待核对的细节与本作原创意象分开记录在[v29-characters.md](v29-characters.md)。

最新全局回访：玩法需要创新，也保留合适的传统方式；信息可以长在静态场景的原画、空处、材质、结构和摆放关系中，不能都靠新增浮层或提示。用户指出P8直接读出908偏简单，当前三位数字开锁稿不发布为最终优化版；比较新增推理与多余手续，优先验证纸画镂空、后层图案与观察动作能否自然形成下一层发现。该要求同样回查旧关，建议按效果取舍，不能为了“创新”增加无法推导的步骤。

适用性检查：每次修正都回顾全部历史要求，但不把每条建议机械复刻到每一关。风格、真实性、空间关系、操作公平、取消/保存、架构与文案是共同底线；具体角色、学校、回忆、生日意象、道具复用方式、机关形式和动画按此处的体验选择，允许明确不加入。需要时可以调整底层架构以支持更好的体验，先确认限制、替代关系和影响范围，再改职责与协议；不把换框架或叠系统本身当作品质提升。

P7经过六轮本体、材料、取景和输入调整，本轮选定原场景同类的薄简装书与单列印刷书名；远景不嵌套额外小柜，托盘落点和原书架层板协调。借阅签、抽看、插排、实际拉屉和独立取物已实操，四种实际下载读回、取消/撤销与下游路径已查。195项测试、296种布局状态和完整路径是功能证据；对照中的整体画面、同类书本和操作细节分别保留，不能将这些数字代替整体审美或玩家盲测。当前合并版本还需完成发布与线上核对。

## 逐项完成的方法

每个项目按同一闭环推进：保存当前可玩基线 → 实际观察问题 → 画出玩法/状态/道具关系 → 至少两个可比较的可玩调整 → 选择并清理被替代实现 → 鼠标、触屏与键盘操作 → 检查前后场景及存档 → 更新演示和证据。小修不为凑版本复制代码；迭代对照放在review中，运行代码只保留选定方案。

完成标准不是“加了什么”。需要回答：看到什么证据、能猜到哪些操作、如何验证假设、失败后怎样恢复、完成后什么改变、旧道具还有没有合理用途。引导随情境出现，主动提醒不成为隐藏解锁条件。

## 素材与动作准备

每个项目在绘图前先列出可见状态、动作与输入，明确需要修改原图、拆分图层、补帧还是只做变换。跟随本表逐关落实，不能因为制作新素材而跳过旧界面、文案、存档和玩法的检查。

- 场景分为固定环境、可移动物件、遮挡前景和完成变化；同一相机保留透视、纸色、阴影方向。远景与特写使用同一份规则状态和坐标依据。
- 动作先做接触/起势/途中/落定的关键帧，再补必要过渡。毛发、眨眼、转头等形变才补画帧；平移、旋转、开合由图层与时间插值完成，避免每帧随机重绘造成闪烁。人物固定脚下锚点、物件固定支点，贴图边缘留足安全区。
- 每组帧记录来源、尺寸、帧区、锚点、时长、播放条件、结束状态和减少动态时的静帧。只预载当前场景及紧邻的解锁场景，验证首屏、解码与切场等待；完整动画不会成为解谜的等待门槛。
- 重绘先从已经接受的场景和官方造型参考出发，不使用私人照片或信件。每组先检查一张关键帧的比例与风格，再制作同组素材，避免大量生成后才发现方向错误。
- 指针归入P2统一交互：小尺寸柔和卡通造型，默认、查看、抓取/拖动和可使用各有轻微区别，热点准确，不遮挡线索。仅精确鼠标启用，触屏不显示；输入框保留文字光标，系统高对比与不支持自定义时回到原生指针。不依赖光标作为唯一提示。

各项目完成时同时复核全局要求；新增帧或特效必须说明它改善的动作，不以图片数量作为质量指标。
