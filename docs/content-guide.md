# 回忆与表达

本作以“被记得、认真对待，以及支持她继续做喜欢的事”为叙事主线。房间、机关和画页属于原创游戏设定，不宣称是真实房间或真实事件的复刻。感谢保持含蓄，不设置表白选择、好感值或关系判定。

## 已确认事实

- 初三开学她坐在男生前面，尚未很熟就送了生日礼物：速写本、好看的书签和书法老师写的字。晚读、背书、值日与光遇逐渐让两人熟络。不填相识公历年份。
- 高一到高三，她认真看练字稿、写评语并纠正。分班前互相去座位；文理分班后，常在晚上放学送过去，第二天晚上换回。
- 2022年夏天逛超市，后来才知道也在为高二生日挑礼物。武大明信片、木书签是当时升学愿望的回应，不据此推断实际就读学校。
- 高三升大一暑假去她的升学宴，她又准备了礼物。大学通过聊天、游戏、电话、互相点吃喝与分享日常保持联系。
- 大一升大二暑假，她邀请看《罗小黑战记2》，妹妹也在。逛街和看电影不改写成只有两个人的约会。
- 大二寒假一起考科目三：她过了，男生当时没过，后来暑假通过并拿到驾照。大二寒假、暑假一起玩剧本杀，她很投入。
- 喜欢画画贯穿始终。高中时间受学业限制；大学主动学习、投入更多时间。今年画漫画、做明信片、挂件与其他周边。主要漫画题材为带土和卡卡西，男生明确支持与赞赏；不编造已报课、付款或职业计划。
- 光遇贯穿始终。常见发型组合是巫师帽＋正太、正太＋樱花。高个子黑脸，矮个子默认矮人面具，可选回归童真面具。两人斗篷可以同款或不同款。
- 高中喜欢魈、流浪者；大一、大二初期喜欢鬼灭柱角色；现在喜欢带土、卡卡西。还喜欢燕云十六声的天泉、九流门，食物语、书、电影、辣食、小猫、小狗和画画。
- 男生大一、大二去过南京。南京大学仅作为喜欢的学校与城市意象，不添加两人共同就读、共同出行等设定。
- 小王子的书、画、笔记本和语录曾多次出现在彼此的礼物中；不把女生直接写成男生“拥有的玫瑰”。
- 木书签、武汉城市金属书签、小王子笔记本、风铃与四阶魔方可参考外观重绘，未知年份留空。书签的测量纸套为游戏附加机关。

另有迈从键盘、小雨伞、零食、护手霜与小瓶、写作本、猫挂件和小狗包装礼物。不填未知的型号、价格或赠送年份。霞柱（时透无一郎）和恋柱（甘露寺蜜璃）的亚克力砖为两件独立物件；风铃不再称为普通吊坠。

推荐过的书与电影完整名称位于 `src/data/memories.js`，不把作品情节做成知识测试。花朵的祝福是为本作写的短句，不宣称是固定花语。
