# 书脊之间 · P7本轮制作与验证

基线a556cf4（V2.9.7）。本轮将书的关系推理、夹页观察、拖排和实际开屉做成同一组物件；其他项目仍按[持续清单](v29-plan.md)推进。开发者走通不等于玩家盲测，也不宣称与绣湖达到相同难度。

旧版五块矩形、同时铺开的关系句和画外箭头，改为借阅签、五本书、夹页与抽屉。保留全部120种排列中唯一解。借阅签放入夹座释放挡条，横拖插排、向上/下抽看书页，顺序合适后实际拉屉；画页A与针留在底面，分别点击拿起。不设置“读过某页”的隐藏门槛，删除没有实际材料用途的透片条件。

对照保留四个有代表性的阶段，制作中另有六轮本体和布局调整。最初手机书没有落在桌面、双人图集误缩成一枚书签、窄书脊挤出两列字，均已替换。较宽书脊解决排字却变成厚礼盒，因此最终直接以原场景的薄本、粉彩、简装和细铅笔线重绘；印刷书名为一列宋体，夹页便条保持手写感。远景撤掉嵌套金框，原书柜与右侧花瓶保留，同一排书和抽屉依实际层板摆放。邻近放映机热区随开屉后的位置重新核对。

借阅签的另一面给出两本间隔，两个书页补充相邻与左右关系；角色书签取自原图集的完整人物，随对应书移动。无效排列的抽屉只轻微受阻，正确时托盘跟着手势完整露出内容；释放前物件仍不可领取，取消后回到闭合处。一次拖排/拉屉只生成一次历史；抽看、翻签、相机选择不写进规则进度。完成后仍可看书，来源不会补货。

规则、库存、素材坐标、纸面、现场、输入与动效分责：books规则；library数据；library-papers共用纸面；puzzles/library渲染；interactions/library输入；motion/library有限过渡。清掉旧矩形书列、箭头、专属重排和重复动效。内容修订12保留旧合法排列与完成，不凭伪造的已解标记发物。

本地证据：195项测试、198个源模块、26定义；320/390/1440各296种页面状态，107个图片引用/99个独立路径完整解码。鼠标、原生Chromium触屏和键盘覆盖装签/取回、横拖、竖向抽看、撤销、无效拉屉、跟手预览、取消/失焦/变更尺寸、减少动态、回访与独立取物。最小320像素取物触区约60×49像素，画页与针完整落在托盘底面。四种实际下载存档在独立空环境读回：半途、开屉未拿、只拿画页、都拿走；四份QA文件已删除。正式新开局的26机关操作到生日结尾通过，证明路径与下游可达，不替代各关独立精修。
