# 第20圈以前

一间可以点击、翻看、反复探索的手绘书房。找到四张画页，借光、穿线、放映、装订，再打开里间的生日桌。

PC 优先，纯静态网页；七个房间视角、16个相互依赖的主线机关、6个独立小机关，以及两校校园折页。角色、场景、道具使用本地栅格插画；连线与轮盘等交互图示使用原生界面。不需要账号、后端或外部素材服务。

[打开游戏](https://liu2024whu-bit.github.io/smallgame/) · [代码结构](docs/architecture.md) · [谜题设计与依赖](docs/puzzle-design.md) · [素材与参考](docs/asset-sources.md)

## 探索方式

- 点击物件观察，左右箭头换视角；也可以使用 Tab、Enter 与键盘方向键。
- 收下物件后可以在物品栏重新查看，有些背面还留着线索。工具可以拖到对应的位置，也可以拿在手里再点目标；使用后仍会保留。
- 手账记录已发现的线索与小小回忆；每个机关都有三层自选提示；默认不展开介绍。
- 未完成的机关可以退一步或复位。独立小机关不会挡住结尾。
- 数字邮匣支持拖轮、键入和拉扣试锁；字母匣支持实体键盘、屏幕键盘、退格与回车。明信片、分拣格、工具背面的孔带与字表给出完整证据，答案回应生日、名字缩写和20岁。
- 木片支持拖放、落点预览、R旋转、Esc取消和取回；书、胶片、印章与画页可直接重排，摆件和音钉也能拖动。轮盘可拖转，棉线可沿轮心与针孔连续穿过；按钮与键盘操作继续保留。
- 小物随探索获得，只展示已经找到的物件。手账的“小记”记录画页添色、翻稿本、看电影、两校折页、猫狗与花；全部收齐、看过生日页后，还有一页彩蛋。
- 雨廊、画桌和生日桌逐步打开。解开的盒盖、抽屉、花架等会留在房间中；生日桌包含留白巧克力与守恒倒壶。
- 迷宫可以直接拖转圆环并推球试路，音乐盒的六枚音钉可直接滑动；花架使用三道升降木轨和可插拔书签。
- 收藏柜边有会眨眼、歪头和抬爪的小黑，猫狗有轻微呼吸与受摸回应；减少动画设置仍然生效。
- 仙林折页可翻看杜厦图书馆、香雪海和一张可以亲手拓印的书桌；专业书放在桌边，不把专业做成问答题。
- 小记收在可翻页的实物手账里，点邮片、花枝、票根查看短介绍；全收齐后，纸艺花园里还有能转动的摇柄和一封信。
- 每一步自动保存在当前浏览器；设置中可以导入、导出存档、关闭声音、减少动画或显示热区。

## 本地运行

需要 Node.js 22 或更新版本，不需要安装依赖。

```sh
node tools/serve.mjs
# http://127.0.0.1:4173

node tools/check.mjs
node --test tests/*.test.mjs
```

也可以运行 `npm run serve`、`npm run check`、`npm test`。请通过 HTTP 访问，浏览器直接打开 `file://` 不支持原生模块加载。发布时保留目录结构，根目录就是 GitHub Pages 入口。

这间书房与机关是游戏虚构。校园建筑按两校公开实景资料绘制；邮戳、格号与孔带仅属于虚构道具，未伪造校史、真实地图、升学或共同游览经历。回忆只留简短锚点，不把未完整提供的经历写成长篇叙事。礼物插画参考已描述的外观重新绘制，未放入原始照片或私人通信。生日文字保持朋友之间的感谢与祝福。

V2.4增加仙林的可选折页、拓印、小记手账和纸艺彩蛋，保持原有主线、存档键与已完成机关。旧存档可以继续补看新增的校园小记；不自动代领新内容。
