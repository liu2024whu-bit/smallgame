## 在小屋里

- 从可以拆开的邀请进入；有进度时直接继续。左上角名字回门口，场景名字打开小屋导航，门后的地方按实际进度开放。
- 点击物件凑近看。工具可以从物品栏拖到机关，也可以先拿起再点目标；用过仍会留着，有些背面另藏线索。
- 画页、书、胶片和木片可直接重排；连续穿线可以原路退回；圆环、字轮、透片与音钉各有自己的操作。拖放支持取消，未解开的机关可以撤销、重来。
- 主线分支会合，不靠角色冷知识或记住私人经历解题。密码的读法就在纸件中；「一点提醒」主动打开才出现。
- 解开的盒盖、抽屉、花架与准备台会留下变化。旧镜子、透片、书签和摇柄在不同地方继续有用。
- 日历圈着2026年10月29日。三张九月夹页分别记着9月1日、2020年9月12日与农历九月初八，能合成另一个六位密码。初见年份未指定；农历生日不混写成当天的公历。
- 收藏柜有小黑的眨眼与抬爪回应；窗边小王子坐在木凳上。猫和金毛可以直接摸摸，也留了键盘按钮。没有把角色白底图直接盖在家具上。
- 小物通过实际探索收下；霞柱与恋柱是独立物件。小记记录翻画、看电影、猫狗、花与校园互动，全收齐、看过生日页后还能给纸艺花园上弦。
- 南京大学仙林折页包含杜厦图书馆、香雪海和虚构的窗边书桌。专业书名使用「马克思主义原理」，不编造课程、同行经历或校内路线。北大楼明确属于鼓楼校区。小蓝鲸与珞珞、珈珈小狐狸按官方文创参照做成纸上图章，折页与手账共用实际收集状态。
- 米色 Yummy 甜美小兔属于这次准备的礼物，生日结尾后才可以拆开，不写成已经收到。
- 每步自动保存；设置提供独立音量、背景音乐、动画、清晰字体、热区、全屏，以及存档导入导出。系统减少动态效果同样生效。

## 本地运行

Node.js 22 或更新版本，无需安装依赖。

```sh
node tools/serve.mjs
# http://127.0.0.1:4173

node tools/check.mjs
node --test tests/*.test.mjs
```

也可使用 `npm run serve`、`npm run check`、`npm test`。通过 HTTP 打开，保留目录结构即可发布到 GitHub Pages。开发服务器支持音频 Range 请求，拖动播放进度不必重新读取整首。
