# 第20圈以前

一间可以慢慢解开的手绘小屋。八个场景、27处机关，画册、蛋糕、琴声和路边的小记。

[开始游戏](https://liu2024whu-bit.github.io/smallgame/)

沿用原游戏的画面与机关，仅调整公开叙述和触屏操作。手机建议横屏，平板与电脑均可游玩；竖屏也能打开。手机可近看并轻拖小屋，钢琴可分低音、高音近看，密码可使用系统键盘输入。

进度自动留在当前浏览器。可建立多份命名进度、导出与导入备份；换设备时需手动带走备份，不会上传到服务器。不要在无痕窗口里长期存放进度。

公开故事使用虚构的称呼与日期。现实身份、私人物件来历、私密维护页、说明截图、存档与开发记录不随网页发布。

五首内置音乐可离线播放，其他录音由唱片架标明的来源联网提供；角色权利属于各自作品权利人，网页为非商业游戏创作。

本地预览：安装Node.js 22及以上后，在此目录运行 `npm run serve`。项目使用原生ESM，无运行依赖。
