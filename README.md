# 第20圈以前

一间可以点击、翻看、反复探索的手绘书房。找到四张画页，借光、穿线、放映、装订，再点亮20岁的生日。

PC 优先，纯静态网页；四个房间视角、12个相互依赖的主线机关、6个独立小机关。角色、场景、道具使用本地栅格插画；连线与轮盘等交互图示使用原生界面。不需要账号、后端或外部素材服务。

[打开游戏](https://liu2024whu-bit.github.io/smallgame/) · [代码结构](docs/architecture.md) · [谜题设计与依赖](docs/puzzle-design.md) · [素材与参考](docs/asset-sources.md)

## 探索方式

- 点击物件观察，左右箭头换视角；也可以使用 Tab、Enter 与键盘方向键。
- 收下物件后可以在物品栏重新查看。合适的工具自动放到机关旁，使用后仍会保留。
- 手账记录已发现的线索与小小回忆；每个机关都有三层自选提示。
- 未完成的机关可以退一步或复位。独立小机关不会挡住结尾。
- 木片支持拖放、落点预览、R旋转、Esc取消和取回；书、胶片、印章与画页可直接重排，摆件和音钉也能拖动。按钮与键盘操作继续保留。
- 礼物随探索逐件收集。手账的“小记”记录画页添色、翻稿本、看电影、猫狗与花；全部收齐、看过生日页后，还有一页彩蛋。
- 每一步自动保存在当前浏览器；设置中可以导入、导出存档、关闭声音、减少动画或显示热区。

## 本地运行

需要 Node.js 22 或更新版本，不需要安装依赖。

```sh
node tools/serve.mjs
# http://127.0.0.1:4173

node tools/check.mjs
node --test tests/*.test.mjs
```

也可以运行 `npm run serve`、`npm run check`、`npm test`。请通过 HTTP 访问，浏览器直接打开 `file://` 不支持原生模块加载。发布时保留目录结构，根目录就是 GitHub Pages 入口。
